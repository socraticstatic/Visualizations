## Name

Chart Color System

## Tagline

Palettes that still work when the colour does not.

## Description

Default chart palettes pass the WCAG 3:1 contrast floor on one background and
silently fail on the other. This plugin treats the background as an input and
audits before you ship.

**Generate** — solve a categorical palette against the surface your chart
actually sits on, then write it into your file as Light and Dark variables,
scoped and code-synced. Every slot carries four encodings: colour, dash,
marker and decal.

**Audit** — measure colours already in your selection for contrast and
colour-vision deficiency, against the layers behind them. It refuses rather
than guessing when there is no honest number to give — an image fill has no
single colour, and the plugin says so instead of inventing one.

**Simulate** — copy your selection once per vision type, so the failure is
something you look at rather than something you read about.

**Mockup** — put a chart on the canvas with its palette already solved, and
the verdict, every relaxation and every advisory drawn into the frame.

**Dev Mode codegen** — your developer selects the frame and gets the ECharts
option, CSS tokens or palette JSON, with the exact encodings.

The solver is deterministic across JavaScript engines, so the palette you see
is the palette your teammate sees and the palette your build produces. That was
not true before 0.8.0: the same input returned three different palettes under
Node, Chrome and Safari, and ten configurations disagreed on whether a palette
passed at all.

Declares `networkAccess: none`. It cannot transmit your file, and does not.

## What publishing still needs from a human

1. The plugin **id**. Figma assigns it; the manifest currently carries the
   development placeholder `1000000000000000001`. It is issued when the plugin
   is created or first published from inside Figma, on the owning account.
2. Upload `icon-128.png` and `cover-1920x1080.png` in the publish modal. The
   manifest has no icon field — verified against Figma's manifest docs — so
   the icon in Figma's Plugins menu comes from the listing and from nowhere
   else. That is why a plugin in development shows Figma's generic glyph.
3. Submit for review.
