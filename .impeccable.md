# Impeccable

## Design Context

### Users

Product and UX designers working inside Figma, mid-task, with the plugin docked in a
420x640 panel beside their file. They are not visiting the plugin; they are in the
middle of something else and need it to answer a question and get out of the way.

The job: get a defensible palette into the file, find out whether the colors already
there survive contrast and colour-vision deficiency, and see the failure rather than
read about it.

### Brand Personality

Direct, evidence-forward, unflattering. The voice of the repo it comes from: it states
numbers, it names what it cannot measure, and it refuses rather than guesses. It never
reassures. A green verdict means something because the tool is willing to give a red one.

Three words: exact, plain, honest.

### Aesthetic Direction

**Native to Figma.** The panel uses Figma's own theme variables, Inter, 11-12px type,
and conventional panel density. It should read as part of Figma, not as a guest with
opinions.

This is a deliberate departure from the impeccable skill's default brief, which asks for
a bold distinctive aesthetic and bans Inter. That brief is right for a site and wrong for
a 420px panel docked inside someone else's application: a plugin that announces itself
reads as misbehaving, and abandoning Figma's tokens would forfeit automatic light/dark.
Blending in is the craft here. Decided explicitly, not defaulted into.

Anti-references: dashboard chrome, card-in-card nesting, coloured accent stripes, hero
metrics, anything that looks like a marketing page wearing a plugin costume.

### Design Principles

1. **Legibility is the product.** This plugin makes accessibility claims. Any text it
   renders that fails the floors it enforces is a self-refuting artifact. The first
   version shipped black text on Figma's dark panel because no colour was set at all.
   That must be impossible to repeat, so the fallback palette is unit-tested against
   the repo's own `contrastRatio`.

2. **Figma's token wins; our fallback is the floor.** Every colour is
   `var(--figma-color-*, <audited fallback>)`. When Figma supplies a value it governs,
   because matching the host is the point. When it does not, our value is one we have
   measured and can defend.

3. **State the number.** Contrast ratios, delta-E, engine version, N caps. Where a
   number exists, show it rather than a reassuring word.

4. **Refusals are first-class UI.** "Cannot audit an image fill" is not an error state
   to hide; it is the product working. Refusals get the same care as results, with the
   reason and the remedy.

5. **Density over air.** 420px wide, beside real work. Tight vertical rhythm, one
   column, no decorative whitespace. Every row earns its height.
